This is a working code package posted online for transparency purposes. This code faithfully reproduces the results in the paper, but lacks full documentation and user-friendliness. It will continue to change until the paper is published. When the project is finalized, full documentation and a user-friendly package will be added.

The data for the empirical application can be obtained from https://www.openicpsr.org/openicpsr/project/120246/version/V1/view .

The paper to which this code package refers is here: https://arxiv.org/abs/2506.20035
